A refusal's sentence says what is true wherever the code is thrown

Five shipped sentences fitted only one of the places their code is thrown, and
a tenant read them on the others: an ended subscription "can no longer be
changed" rather than only its plan, a blocked plan change no longer says
"during onboarding" when a version switch is blocked, a cancellation that
changed while ending at once is not called a moved date, a request without a
user is not said to lack a tenant, and a cancelled bundle booking is not named
by its internal id. `resolveErrorMessage` also gives a sentence that names a
value the body did not bring way to the server's message, as the
administration does, rather than showing the placeholder.
